# Documentación de Endpoints - HU34 - Registrar información personal de tutor

---

### Resumen de la Historia de Usuario

**HU:** HU34 - Registrar información personal de tutor
**Descripción:** Como tutor, quiero registrar información personal para generar confianza en los estudiantes.
**Criterios de Aceptación:** Esta historia de usuario se centra en la primera etapa del registro de un tutor, donde se ingresan datos básicos como nombre completo, número de WhatsApp, facultad, semestre actual y una biografía corta. Los criterios detallan validaciones exhaustivas para cada campo (obligatoriedad, longitud mínima/máxima, tipo de caracteres) y aseguran que, tras un registro exitoso, el sistema redirige a la siguiente etapa de definición de disponibilidad.

---

### Tabla de Endpoints

| # | Método | Ruta Completa          | Descripción                                        | Autenticación      | Controller                         | Service                       | DTO Request            | DTO Response           |
| - | ------ | ---------------------- | -------------------------------------------------- | ------------------ | ---------------------------------- | ----------------------------- | ---------------------- | ---------------------- |
| 1 | POST   | /api/tutor/datos-basicos | Registra o actualiza los datos básicos de un tutor | JWT (JwtAuthGuard) | TutorController.registrarDatosBasicos | TutorService.registrarDatosBasicos | RegistrarDatosBasicosDto | TutorEntity (o similar) |

---

### Detalle de Endpoints

### 1. POST /api/tutor/datos-basicos

**Descripción:**
Este endpoint permite a un tutor registrar o actualizar su información personal básica, incluyendo su nombre completo, número de WhatsApp, facultad, semestre actual y una biografía corta. Es la primera etapa del proceso de "Completar Perfil" del tutor.

**Autenticación:**
✅ **Requerida:** Se espera un token JWT válido en el encabezado `Authorization`.
Guard: `JwtAuthGuard` (implícito, aunque el código proporcionado no lo muestra explícitamente en el controller, se asume por el flujo de un usuario autenticado).

**Parámetros de Ruta:**
Ninguno

**Parámetros de Consulta:**
Ninguno

**Cuerpo de la Petición:**
`RegistrarDatosBasicosDto`

| Propiedad         | Tipo         | Requerido | Descripción                                                                | Validaciones                                                                                                                                                                                                                                                                                                                                     |
| :---------------- | :----------- | :-------- | :------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nombreCompleto`  | `string`     | Sí        | Nombre completo del tutor.                                                 | - `IsString`: Debe ser una cadena de texto.<br>- `IsNotEmpty`: Es obligatorio.<br>- `MinLength(3)`: Mínimo 3 caracteres (AC3).<br>- `MaxLength(60)`: Máximo 60 caracteres (AC4).<br>- `Matches(/^[a-zA-Z\s]+$/)`: Solo letras y espacios (AC5).                                                                                                      |
| `numeroWhatsapp`  | `string`     | Sí        | Número de WhatsApp del tutor.                                              | - `IsNumberString`: Solo debe contener dígitos (AC8).<br>- `IsNotEmpty`: Es obligatorio.<br>- `MinLength(10)`: Debe tener entre 10 y 13 dígitos (AC6).<br>- `MaxLength(13)`: Debe tener entre 10 y 13 dígitos (AC7).                                                                                                                              |
| `facultad`        | `Facultades` | Sí        | Facultad a la que pertenece el tutor. (Ej. 'FIS - Sistemas', 'FCEC').      | - `IsEnum(Facultades)`: Debe ser una de las facultades predefinidas.<br>- `IsNotEmpty`: Es obligatorio (AC2).                                                                                                                                                                                                                                |
| `semestreActual`  | `Semestres`  | Sí        | Semestre actual del tutor. (Ej. '4° Semestre').                            | - `IsEnum(Semestres)`: Debe ser uno de los semestres predefinidos.<br>- `IsNotEmpty`: Es obligatorio (AC2).                                                                                                                                                                                                                                 |
| `biografiaCorta`  | `string`     | Sí        | Breve descripción o biografía del tutor.                                   | - `IsString`: Debe ser una cadena de texto.<br>- `IsNotEmpty`: Es obligatorio (AC2).<br>- `MinLength(20)`: Mínimo 20 caracteres (AC9).<br>- `MaxLength(300)`: Máximo 300 caracteres (AC10).                                                                                                                                                   |

```json
{
  "nombreCompleto": "Daniela Castro",
  "numeroWhatsapp": "593991234567",

  "semestreActual": "4° Semestre",
```
